# media-studio
Media Studio is a Windows desktop app that puts all my media jobs in one place. It cleans, converts, compresses and upscales video on the GPU, finds, transcribes and translates subtitles in any language and merges them in, adds royalty-free music, and files finished work into tidy folders. Everything runs locally from one queue.
